# Rugby LIVE — atlikušais darbs

- Match Control REQUEST ACCESS pieprasījumam pievienot operatora vārdu un privātu e-pastu, lai Admin zina, kurš piesakās.
- Apstiprināto operatoru sasaistīt ar vienreizējo piekļuvi un faktiski vadītajām spēlēm; pēc tam izmantot šo uzskaiti Touchline Heroes.
- Pievienot atsevišķu piekrišanu vārda publicēšanai Touchline Heroes. Publiskošanu izvēlas Admin; e-pastu publiski nerādīt. Ievadīts vārds pats par sevi neapstiprina identitāti.
- Touchline Heroes un izlozes publiskās sadaļas pagaidām saglabāt paslēptas.

Darbs pēc noklusējuma tikai test branch. Main un Owner aktivizāciju neaiztikt.
